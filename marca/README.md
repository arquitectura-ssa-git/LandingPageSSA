# Material de marca SSA

Subí acá todo lo que sirva para diseñar la landing. En GitHub: entrá a la carpeta que corresponda → **Add file → Upload files** → arrastrá los archivos → **Commit changes** (directo a `main`).

| Carpeta | Qué va | Formatos ideales |
|---|---|---|
| `tipografias/` | Fuentes de la marca (todas las variantes: Light, Regular, Medium, Bold…) y su licencia | `.woff2`, `.woff`, `.otf`, `.ttf` + licencia |
| `logos/` | Logo principal, isotipo "SSA", versiones en blanco/negro, favicon si existe | `.svg` (mejor), `.png` con fondo transparente, `.pdf`/`.ai` |
| `manual/` | Manual de marca / brandbook | `.pdf` |
| `fotos/` | Renders y fotos de obra, retratos del equipo | `.jpg` en alta (mín. 2400 px de ancho). Nombralas por proyecto: `vilabonita-01.jpg` |
| `textos/` | Textos, datos de proyectos, premios, contacto | `.docx`, `.pdf`, `.txt`, `.md` o lo que tengas |

Notas:
- GitHub web acepta archivos de hasta **25 MB** cada uno. Para lotes grandes de fotos o archivos más pesados, usá una carpeta compartida de Google Drive y pasá el link.
- Las tipografías tienen que tener licencia de uso **web** para poder publicarlas en el sitio. Si la licencia es solo de escritorio, avisá y buscamos una alternativa equivalente.
